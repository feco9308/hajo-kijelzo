# Korábbi vizsgálatok

Ebben a mappában a hardver beüzemelése során készült feljegyzések vannak.
A bennük szereplő ágak, időzítések és bekötési próbák történeti állapotokat
írnak le. Az aktuális program és a végleges bekötés a projekt fő README-jében
szerepel. A továbbfejlesztés a `main` ágon történik.

A repository rendezése előtt az összes Git-ágról teljes bundle-mentés
készült a gép `C:\Users\User\Kijelzo-backups` mappájába.
